BÀI 4: THỰC HÀNH CẤU HÌNH - CÀI ĐẶT HYBRID AI RUNTIME

1. FILE build.gradle

plugins {
    id 'java'
    id 'org.springframework.boot' version '3.5.3'
    id 'io.spring.dependency-management' version '1.1.7'
}

group = 'com.example'
version = '1.0.0'

java {
    toolchain {
        languageVersion = JavaLanguageVersion.of(21)
    }
}

repositories {
    mavenCentral()
}

ext {
    springAiVersion = '1.0.0'
}

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web'
    implementation 'org.springframework.ai:spring-ai-starter-model-ollama'
    implementation 'org.springframework.ai:spring-ai-starter-model-openai'
}

dependencyManagement {
    imports {
        mavenBom "org.springframework.ai:spring-ai-bom:${springAiVersion}"
    }
}

Giải thích:
- Cả 2 starter (ollama + openai) được khai báo cùng lúc để hỗ trợ chuyển đổi giữa
  hai môi trường không cần sửa mã nguồn.
- spring-ai-bom (springBom) quản lý version thống nhất cho các starter Spring AI,
  tránh xung đột version.

2. FILE application-local.properties

spring.ai.ollama.base-url=http://localhost:11434
spring.ai.ollama.chat.options.model=qwen2.5-coder:7b

3. FILE application-cloud.properties

spring.ai.openai.api-key=${OPENROUTER_API_KEY}
spring.ai.openai.base-url=https://openrouter.ai/api/v1
spring.ai.openai.chat.options.model=google/gemini-2.5-flash

Giải thích:
- API Key được lấy từ biến môi trường OPENROUTER_API_KEY (cú pháp ${...}), không
  ghi cứng vào file.
- OpenRouter dùng API tương thích chuẩn OpenAI nên cấu hình qua starter Open AI,
  chỉ cần đổi base-url sang https://openrouter.ai/api/v1.

4. FILE application.properties

spring.profiles.active=local

5. CÁCH CHẠY ỨNG DỤNG Ở PROFILE CLOUD TỪ CLI

Trước tiên set biến môi trường chứa API key (Windows PowerShell):
    $env:OPENROUTER_API_KEY = "sk-xxxx"

Cách 1 - truyền profile qua command line (ưu tiên, không cần sửa file):
    .\gradlew.bat bootRun --args="--spring.profiles.active=cloud"

Linux/MacOS:
    ./gradlew bootRun --args='--spring.profiles.active=cloud'

Cách 2 - set biến môi trường SPRING_PROFILES_ACTIVE:
    $env:SPRING_PROFILES_ACTIVE = "cloud"
    .\gradlew.bat bootRun

Khi active profile cloud: Spring Boot tự động nạp application-cloud.properties
(thay thế config Ollama bằng OpenRouter/Gemini), còn profile local mặc định dùng
Ollama. Không cần đổi bất kỳ dòng mã Java nào.
